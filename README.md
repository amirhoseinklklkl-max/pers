# شهر فارسی - بازی جهان باز دو‌بعدی فارسی

یک بازی موبایل دو‌بعدی با زبان فارسی برای سنین ۰ تا ۱۸ سال. در این بازی می‌توانید در شهر آزاد بگردید، با NPCها صحبت کنید، شغل داشته باشید، ماشین و موتور بخرید، در بانک وام بگیرید، ملک بخرید، لباس عوض کنید، غذا بخورید و زندگی کنید!

## ویژگی‌ها

### نقشه شهر بزرگ
- **۱۸+ ساختمان** با کاربرد متفاوت: خانه، مغازه لباس، رستوران، آرایشگاه، نمایشگاه ماشین، گاراژ، بانک، کلانتری، بیمارستان، پارک، باشگاه، سوپرمارکت، سینما، پمپ بنزین، مرکز کاریابی، مدرسه، کتابخانه، فرودگاه هلیکوپتر، مغازه دوچرخه
- خیابان‌های افقی و عمودی با خط‌چین و پیاده‌رو
- درختان و چراغ‌های خیابان (که شب‌ها روشن می‌شوند)
- ماشین‌های پارک شده‌ی تصادفی

### کنترل بازی
- **جوی‌استیک مجازی** سمت چپ پایین برای حرکت (لمس هر نقطه از ربع پایین-چپ)
- **دکمه اکشن** (سبز بزرگ) سمت راست پایین - متن آن با توجه به موقعیت شما تغییر می‌کند:
  - "ورود" وقتی نزدیک ساختمان هستید
  - "صحبت کن" وقتی نزدیک NPC هستید
  - "سوار شو" وقتی نزدیک ماشین خودتان هستید
- **دکمه کار** (نارنجی) وقتی شغل دارید ظاهر می‌شود
- **دکمه خروج از ماشین** وقتی سوار ماشین هستید
- **دکمه منو** (≡) گوشه بالا راست

### سیستم شخصیت‌سازی
- انتخاب جنسیت (پسر/دختر)
- انتخاب رنگ مو (مشکی، قهوه‌ای، بلوند، قرمز)
- انتخاب مدل مو (کوتاه، بلند، طاس)
- انتخاب رنگ لباس (۶ رنگ)
- انتخاب رنگ شلوار
- انتخاب رنگ پوست (روشن، متوسط، تیره)

### چرخه شبانه‌روز
- یک روز کامل در **۵ دقیقه** (۳۰۰ ثانیه)
- ۶ فاز: سپیده‌دم، صبح، ظهر، عصر، غروب، شب
- رنگ آسمان و محیط با گذشت زمان تغییر می‌کند
- چراغ‌های خیابون و پنجره‌ها در شب روشن می‌شوند

### شغل‌ها (۶ شغل)
1. **پیک** - تحویل بسته‌ها (۱۵۰۰ تومان به ازای هر بسته)
2. **آشپز** - پخت و پز غذا (۸۰۰ تومان به ازای هر غذا)
3. **فروشنده ماشین** - خرید و فروش ماشین با سود متغیر
4. **فروشنده لباس** - فروش لباس با سود متغیر
5. **آرایشگر** - خدمات آرایشی به مشتری‌ها (۵۰۰ تومان)
6. **پلیس** - گشت زدن در شهر (۲۰۰۰ تومان به ازای هر ساعت)

### وسایل نقلیه قابل خرید
- **دوچرخه** - ۵۰۰ تومان (شروع با دوچرخه رایگان)
- **موتور سیکلت** - ۸٬۰۰۰ تومان
- **سدان خانوادگی** - ۲۵٬۰۰۰ تومان
- **ماشین شاسی‌بلند** - ۴۵٬۰۰۰ تومان
- **وانت** - ۳۵٬۰۰۰ تومان
- **ماشین اسپرت** - ۱۲۰٬۰۰۰ تومان
- **هلیکوپتر** - ۵۰۰٬۰۰۰ تومان

### تنظیمات ماشین (گاراژ)
- **تغییر رنگ ماشین** (۱۰ رنگ)
- **نصب توربو** - ۵٬۰۰۰ ت (افزایش ۲۰٪ سرعت)
- **نصب نیترو** - ۸٬۰۰۰ ت
- **چرخ‌های جدید** - ۳٬۰۰۰ ت
- **اسپویلر** - ۴٬۰۰۰ ت
- **ارتقای موتور** - ۱۰٬۰۰۰ ت (افزایش ۳۰٪ قدرت)

### سیستم بانک و اقتصاد
- **سپرده‌گذاری** پول در بانک (با سود سالانه ۸٪)
- **گرفتن وام** (با بهره سالانه ۱۵٪)
- **برداشت و بازپرداخت وام**
- **درآمد روزانه از املاک**

### املاک قابل خرید
- **آپارتمان ۱** - ۵۰٬۰۰۰ ت (اجاره ۲۰۰ ت/روز)
- **آپارتمان ۲** - ۷۵٬۰۰۰ ت (اجاره ۳۵۰ ت/روز)
- **خانه ویلایی ۱** - ۲۰۰٬۰۰۰ ت (اجاره ۱٬۰۰۰ ت/روز)
- **مغازه ۱** - ۳۵۰٬۰۰۰ ت (اجاره ۱٬۸۰۰ ت/روز)
- **ویلا** - ۸۰۰٬۰۰۰ ت (اجاره ۵٬۰۰۰ ت/روز)

### NPCها و دیالوگ‌ها
- ۲۵+ شخصیت غیربازیکن (NPC) با نقش‌های مختلف: شهروندان عادی، فروشنده‌ها، پلیس، بانکیار، آشپز، آرایشگر و...
- هر NPC دیالوگ مخصوص به خودش را دارد
- NPCها در شهر حرکت می‌کنند و سرگردان هستند

### سیستم سلامتی
- **گرسنگی** - با خوردن غذا کاهش می‌یابد، اگر صفر شود سلامتی کاهش می‌یابد
- **انرژی** - با کار کردن کاهش، با استراحت و خواب افزایش می‌یابد
- **سلامتی** - اگر صفر شود، در بیمارستان احیا می‌شوید و ۱۰٪ پول شما از دست می‌رود

### خدمات مغازه‌ها
- **رستوران**: ۶ نوع غذا (ساندویچ، کباب، پیتزا، آبمیوه، چای، بستنی)
- **مغازه لباس**: ۷ نوع لباس و اکسسوری
- **آرایشگاه**: ۴ خدمت (اصلاح مو، اصلاح ریش، رنگ مو، مدل مو)
- **باشگاه ورزشی**: افزایش سلامتی (۲۰۰ ت)
- **سینما**: افزایش انرژی (۵۰۰ ت)

### ذخیره خودکار
- بازی هنگام خروج از اپلیکیشن به‌صورت خودکار ذخیره می‌شود
- منوی توقف (دکمه ≡) امکان ذخیره دستی را فراهم می‌کند
- حالت "ادامه بازی" در منوی اصلی، بازی ذخیره‌شده را بارگذاری می‌کند

## نحوه اجرا در اندروید استودیو

### پیش‌نیازها
- **Android Studio** نسخه Hedgehog (2023.1.1) یا بالاتر
- **JDK 17** (همراه با Android Studio نصب می‌شود)
- **Android SDK** با API Level 34 (Android 14)
- حافظه RAM حداقل ۸ گیگابایت (پیشنهادی ۱۶ گیگ)

### مراحل نصب و اجرا

1. **کپی کردن پروژه**
   - فایل ZIP پروژه را در یک مسیر دلخواه (مثلاً `D:\AndroidProjects\`) از حالت فشرده خارج کنید.

2. **باز کردن در Android Studio**
   - Android Studio را باز کنید.
   - `File` → `Open` را بزنید.
   - به پوشه `PersianCityGame` بروید و `OK` را بزنید.
   - صبر کنید تا Gradle sync انجام شود (اولین بار ممکن است ۵-۱۰ دقیقه طول بکشد تا وابستگی‌ها دانلود شوند).

3. **تنظیم SDK (در صورت نیاز)**
   - اگر خطای SDK ندارید، این مرحله را رد کنید.
   - در صورت خطا: به فایل `local.properties.template` نگاه کنید، آن را به `local.properties` کپی کنید و مسیر SDK خود را وارد کنید.
   - یا: از منوی `File` → `Project Structure` → `SDK Location`، مسیر Android SDK را تنظیم کنید.

4. **اجرای بازی**
   - یک گوشی اندرویدی را با USB به کامپیوتر وصل کنید (با فعال بودن USB Debugging در Developer Options).
   - یا یک Emulator از نوع **Phone** با orientation افقی بسازید.
   - دکمه **Run** (مثلث سبز) را بزنید.
   - بازی روی دستگاه/امولاتور نصب و اجرا می‌شود.

5. **خروجی گرفتن APK**
   - از منوی `Build` → `Build Bundle(s) / APK(s)` → `Build APK(s)` را انتخاب کنید.
   - صبر کنید تا build تمام شود.
   - فایل APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.
   - می‌توانید این فایل را روی هر گوشی اندرویدی نصب کنید.

6. **خروجی Release (برای انتشار)**
   - از منوی `Build` → `Generate Signed Bundle / APK` را انتخاب کنید.
   - یک keystore بسازید یا انتخاب کنید.
   - نسخه Release را بسازید.

### نکات مهم

- **جهت نمایش**: بازی فقط در حالت **افقی (Landscape)** کار می‌کند. در Manifest این تنظیم شده است.
- **حداقل نسخه اندروید**: Android 7.0 (API 24)
- **نسخه هدف**: Android 14 (API 34)
- اگر اولین بار است که پروژه را اجرا می‌کنید، Android Studio ممکن است Gradle wrapper را دانلود کند (حدود ۱۰۰ مگابایت).
- اگر هنگام دانلود وابستگی‌ها به مشکل برخوردید، یک VPN فعال کنید.

## معماری پروژه

### ساختار پکیج‌ها
```
com.persiancity.game/
├── MainActivity.kt              # اکتیویتی اصلی
├── data/
│   ├── GameData.kt             # داده‌های ثابت بازی (ماشین‌ها، آیتم‌ها، املاک)
│   └── PersianTexts.kt         # تمام متن‌های فارسی بازی
├── entities/
│   ├── Player.kt               # بازیکن (شخصیت کاربر)
│   ├── NPC.kt                  # شخصیت‌های غیربازیکن
│   └── Vehicle.kt              # ماشین، موتور، دوچرخه، هلیکوپتر
├── game/
│   └── GameView.kt             # نمای اصلی بازی (SurfaceView + Game Loop)
├── systems/
│   ├── Economy.kt              # پول، بانک، وام، ملک
│   ├── JobSystem.kt            # مدیریت شغل‌ها
│   └── SaveSystem.kt          # ذخیره/بارگذاری بازی
└── world/
    ├── Building.kt             # کلاس ساختمان
    ├── DayNightCycle.kt        # چرخه شبانه‌روز
    └── World.kt                # نقشه شهر
```

### موتور بازی
- **SurfaceView** برای رندرینگ با Canvas API (بدون موتور بازی خارجی)
- **Game Loop** اختصاصی با هدف ۶۰ FPS
- تمام گرافیک با primitives (مستطیل، دایره، مسیر) کشیده می‌شود - هیچ asset خارجی لازم نیست
- دوربین نرم به دنبال بازیکن حرکت می‌کند
- Culling: فقط ساختمان‌ها و موجودیت‌های داخل کادر دید رسم می‌شوند

### ذخیره‌سازی
- **SharedPreferences** + **Gson** برای سریالایز کردن وضعیت بازیکن
- شامل: مختصات، آمار، پول، شغل، اموال، ماشین‌ها، لباس‌ها و ارتقاها

## سفارشی‌سازی و توسعه

### اضافه کردن ساختمان جدید
در فایل `World.kt` در متد `generateCity()`، یک Building جدید اضافه کنید:
```kotlin
buildings.add(Building(
    id = "my_shop",
    name = "مغازه من",
    type = BuildingType.SUPERMARKET,  // یا یک نوع جدید
    x = 1500f, y = 800f,
    width = 220f, height = 180f,
    wallColor = Color.parseColor("#FFFFC107"),
    roofColor = Color.parseColor("#FFF57F17")
))
```

### اضافه کردن NPC جدید
در متد `spawnNPCs()` در `World.kt`:
```kotlin
npcs.add(NPC(
    x = 1500f, y = 850f,
    name = "نام NPC",
    role = NPC.Role.CIVILIAN,
    shirtColor = Color.parseColor("#FF1976D2")
))
```

### اضافه کردن آیتم جدید به مغازه‌ها
در `GameData.kt` در لیست `FOODS` یا `CLOTHING`:
```kotlin
FoodDef("kabab_chenjeh", "کباب چنجه", 2500, 60, 20)
```

### تغییر مدت زمان یک روز
در فایل `DayNightCycle.kt` متغیر `dayDurationSec` را تغییر دهید:
```kotlin
private val dayDurationSec: Float = 600f  // ۱۰ دقیقه
```

- در برخی دستگاه‌های قدیمی ممکن است رندرینگ کند باشد. در صورت بروز این مشکل، تعداد درختان و NPCها را در `World.kt` کاهش دهید.
